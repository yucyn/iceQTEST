# 備課：進攻區低位循環與門後反向

來源：使用者提供 BENCHIQ / benchiq.hockey IG 螢幕錄影。長度21.9秒，主要動作約0–18秒，後段為品牌結尾。

三情境：0–4秒低位循環、4–10秒門後反向、10–18秒再次取球與高位連結。擷取時間為約略觀察範圍。

影片畫面可見 Low Cycle、Inside F Retrieves、Find the Passing Lane、Area Pass 等提示。

學習室版為5名己方+5名對手的既有格式。僅一位D1有來源依據；其餘對手置於遠端，不參與本題。獨立預覽只畫5名己方與D1。尚待教練確認任務對照、細部出球順序與門前最後一傳；沒有把原片直接推定為射門得分。
